# Criptomoedas API

Uma aplicação desenvolvida com React, TypeScript e Vite que permite visualizar informações em tempo real sobre criptomoedas utilizando a API da CoinCap.

## Tecnologias
- React
- TypeScript
- React Router
- CSS Modules
- CoinCap API

## Funcionalidades
- ✅ Listagem de criptomoedas
- ✅ Página de detalhes
- ✅ Preços em tempo real
- ✅ Capitalização de mercado
- ✅ Volume das últimas 24 horas
- ✅ Variação das últimas 24 horas
- 🚧 Pesquisa (em desenvolvimento)

## Como executar
npm install
npm run dev
